# Yoga Assistant : A system for Yoga Pose Detection and Correction <br>
User can select the available yoga poses from the UI and can perform that selected pose. The system detects the yoga pose the user is performing and provides correction guidance through voice feedback for correcting the pose. This system is trained on 3 different models RFC, CNN and more.
